# Two LANs Connected Using Static Routing

## Project Overview
A network simulation built using Cisco Packet Tracer to connect two separate LANs through two routers.

## Network Topology
- 2 Routers
- 2 Switches
- 4 PCs

## Technologies
- IPv4 Addressing
- Subnet Masks
- Default Gateways
- Static Routing
- Cisco IOS CLI
- ICMP Ping and Network Troubleshooting

## Configuration
- Configured IP addresses for PCs and router interfaces.
- Configured static routes to enable communication between LANs.
- Verified connectivity using ping.
- Inspected routing tables using `show ip route`.

## Files
- `Two-LAN-Static-Routing.pkt`: Packet Tracer project file.
- `screenshots/`: Network topology and test results.

## How to Open
Open the `.pkt` file using Cisco Packet Tracer.
